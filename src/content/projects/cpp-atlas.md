The aim is that a scientist can read a mathematical model in a paper, understand its assumptions, design an algorithm for it, implement it in C++, check that the code is correct, run simulation experiments and draw conclusions that say no more than the model supports.

The curriculum is a map. The foundations of the language lie to the west and four modelling destinations to the east: algorithm design, numerical integration, stochastic modelling and individual-based modelling. A last region, scientific inference, is about what simulation output can and cannot support. The map holds 124 concepts, and 74 lessons with worked C++ examples, step-through traces and knowledge checks. Nothing is locked, and progress stays in the browser, with no accounts.

The browser laboratories are written in TypeScript and are labelled as simulations; the site does not run C++. The C++ programs are compiled and run in continuous integration and checked against the laboratories. Figures and code colours follow [Vellum](/work/vellum/).

The curriculum follows the University of Groningen course manual *Programming in C++ for Biologists*. The site is independent, is not endorsed by the University, and reproduces none of the manual's exercises or solutions.
