A simple project is just a board. As a project grows, work packages, milestones and deliverables, budgets, KPIs, risks, meetings and automations can be switched on. Everything lives in one connected database, so a change in one view shows in every other: board, table, calendar, timeline, dashboard and map.

For funded projects with several partners it holds the planning, reporting and financial controls: budgets by partner, work package, category, year and reporting period, with decimal-safe calculations, Excel import and XLSX, CSV and PDF export.

The front end is React and TypeScript, hosted on GitHub Pages; the back end is Supabase. Every permission, including the narrower access to financial data, is enforced in the database, and the browser holds only the public key. Licensed under MIT.
